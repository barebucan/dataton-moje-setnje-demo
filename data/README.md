# Podaci i podrijetlo

`raw` sadrži ulazne podatke, `city-processed` slojeve prilagođene karti i planeru, a `provenance` metapodatke o izdavateljima, izvornim poveznicama i preuzimanju. `curated-landmarks.json` i `voice-route-stories.json` pripremaju kontekst za glasovni vodič. [Licence i atribucije](../ATTRIBUTION.md)
