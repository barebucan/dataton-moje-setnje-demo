# Poslužiteljski dio

- `app.py` povezuje sučelje s izračunom ruta i uslugom vodiča.
- `loop_quality.py` vrednuje pješačke petlje.
- `voice.py`, `voice_context.py` i `voice_provider.py` upravljaju razgovorom, kontekstom lokacije i pozivima prema pružatelju glasovne usluge.

Lokacijski kontekst povezuje pitanje s mjestima uz odabranu trasu. Istraživačka usluga vraća nalaz i izvore razgovornom vodiču.
